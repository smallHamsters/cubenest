# CubeNest — 쌓기나무 단원 전체 유형 지도 (문제집 실측)

> **버전:** v0.3 (표본 수렴 검증 완료) · **작성일:** 2026-08-16 · **근거:** 초6-2 문제집 **4종**(교과서형·수학의신/최고수준·개념플러스유형·파워유형[유형1~14 카탈로그]) 실측 약 55장 · 마스터 v1.6.2 §4.4
> **정렬 기준:** 개념플러스유형 목차의 **공식 소단원 1~7**(방향→삼면도→숨은나무→삼면도역→위수→층별→모양만들기)에 우리 A~J를 매핑. 세 문제집이 이 뼈대로 수렴 확인.
> **목적:** 실제 문제집이 다루는 **모든 유형**을 지도로 정리하고, 우리 재개편 매핑(19종)의 **누락**을 드러낸다. quiz 적합도(자동채점·서버생성 가능)를 함께 표기해 착수 우선순위를 잡는다.
> **좌표:** 위=+y, 앞=+z, 옆(오른쪽)=+x (마스터 3.2).

## 0. 핵심 발견 2가지

1. **"안 보이는 나무"는 단일 계산이 아니라 제시(given)에 따라 갈린다.** 문제집은 **겨냥도만으론 개수를 절대 확정하지 않는다**(11 or 12개 예시). 개수를 물으면 반드시 **위모양+수 / 삼면도 / 층별** 중 하나를 더 준다. → **우리 기존 hidden 버그(겨냥도만+개수)의 정답.** (개념플러스유형 소단원3 개념: "보이는 위 면 == 위모양 → 숨은 나무 없음, 다르면 1~2개 있음"으로 교과서가 명문화.)
2. **우리 매핑(19종)은 "개수·삼면도·층별·은닉"은 잘 덮지만, 통째로 빠진 유형군이 6개**다: 방향관찰 · 관계잇기 · 위모양수 · 최대최소 확장 · 조작(빼기/더쌓기/정육면체/색칠) · 모양만들기(폴리큐브).

### 0.1 공식 소단원(교과) ↔ 우리 유형군 대응
| 교과 소단원 | 내용 | 우리 유형군 | 커버 |
|---|---|---|---|
| **1. 어느 방향에서 본 모양** | 방향·관점(사진/조형물) | **I** | ❌ 신규(후순위) |
| **2. 쌓은 모양→위·앞·옆** | 삼면도 그리기·읽기 | **C·D** | ✅/⚠️ |
| **3. 쌓은 모양+위모양→개수** | 숨은 나무 유무·개수 | **A** | ✅(재정의) |
| **4. 위·앞·옆→개수** | 삼면도 역(개수·최대최소) | **A-d·G** | ✅/❌ |
| **5. 위에 수 쓰기→개수** | numbered top | **A-c·F** | ✅/❌ |
| **6. 층별 모양→개수** | 층별 | **A-e·E** | ✅ |
| **7. 여러 가지 모양 만들기** | 폴리큐브·회전동일 | **J** | ❌ 신규 |
| (기본 개수·부피·겉넓이) | measure | **B** | ✅ |
| (심화) 조작·색칠·정육면체 | reveal 변화 | **H** | ❌ 신규 |

→ **우리 A~J가 교과 소단원을 빠짐없이 포괄.** 세 문제집이 이 뼈대로 수렴하므로 표본 충분.

### 0.2 표본 수렴 검증 (4종 문제집) + 공식 힌트
**파워유형(유형1~14 카탈로그)** 이 우리 A~J와 1:1 대응 — **새 유형군 0개**. 오히려 문제집이 계산 공식을 명시해 서버 계산을 확정해준다:
| 문제집 유형 | 우리 | 확정된 공식(서버 계산) |
|---|---|---|
| 유형9 n층 개수 | G-c | `층 개수 = 위모양에서 n 이상 적힌 칸 수` |
| 유형13 겉넓이 | B-c | `겉넓이 = (위+앞+옆 면수)×2 × edge²` (마스터 §4.2 일치) |
| 유형12 색칠 | H-d | `색칠 수 = 큰 정육면체 꼭짓점 쌓기나무 수`(꼭짓점8·모서리·면·속) |
| 유형8 정육면체 완성 | H-c | `더 필요 = 최소 정육면체 개수 − 현재` |
| 유형14 조건 모양 수 | G-c변형 | `= 1층 쌓기나무 개수`(모호칸 조합) |
| 유형11 최대·최소 | G | `reverseCounts`(min/max) |
→ **4종 표본 완전 수렴.** 우리 유형 지도가 시판 문제집 전 유형을 포괄함이 검증됨. 추가 조사 불필요.

## 2. 우리 매핑 대비 — 신규로 추가해야 할 것

**❌ 완전 신규(매핑에 없음):**
- **D-d 다른 것 찾기**(앞/옆 다른 하나) · **E-d 잘못된 층** · **F-d 관계 잇기** · **E-e/F-c 모양 찾기(mc)**
- **G-b 위+앞/옆 최대최소** · **G-c 층 조건 개수**
- **H-a~d 조작**(더쌓기·빼기·정육면체 완성·색칠 정육면체)
- **I 방향 관점**(후순위) · **J 폴리큐브**(회전동일성)

**신규 서버 계산 필요:**
- `viewsPlusTop → minmax` (G-b): 위모양+한 방향으로 최대/최소.
- `layerConstraintCount` (G-c): "n층 이상" 등 조건 개수.
- `completeToCube(sh)` (H-c): 최소 정육면체 − 현재 개수.
- `paintedCubeCount(n, faces, k)` (H-d): n³ 정육면체 겉면 색칠 시 k면 색칠된 나무 수(꼭짓점3·모서리2·면1·속0).
- `perturbThenViews(sh, ops)` (H-a/b): 더/빼기 후 삼면도.
- `polycubeCanonical`·`enumPolycubes(N)`·`rotEquiv(a,b)` (J): 24방향 정규화·열거·동일 판정.
- `matchPairs` (F-d/I-a): 짝짓기(생성은 자명, 채점=대응 일치).
- `oddOneOut(view)` (D-d): 한 개만 다른 뷰를 갖도록 생성.

**기존 계산 재사용:** hiddenCells·silhouettes·reverseCounts·reverseShapes·heightMap·stats·surfaceArea·layerViews/Counts.

### 5.2 답안 격자 규칙 (확정 · A안)
그리기·고르기·수쓰기 등 **격자가 나오는 답안은 항상 정사각 N×N**으로 통일한다.
- **N = max(gx, gz, maxH)** (해당 모양이 쓰는 축들의 최댓값).
- **적용:** drawSil(위·앞·옆 모두 N×N 패딩)·drawLayers·markCount·gridHint·options(sil 후보)·top 격자.
- **예:** 4×4×3 모양의 위·앞·옆 그리기 → 세 답란 모두 **4×4**(앞·옆을 4×3으로 내지 않음). 3×3×3 → 3×3.
- **정합:** 교과서 답안지 관례(위·앞·옆을 같은 정사각 격자)와 일치. 채점·렌더 단순화.
- **난이도 연동:** N이 곧 격자 난이도 동인 → **N=3 중 / N=4 상 / N=5 최상**으로 등급(§5.1 공통축과 통일).
- **구현 메모:** 실제 실루엣은 원래 치수로 계산 후 **N×N 격자에 좌상단(또는 규약 위치) 정렬해 패딩**. 정렬 규약은 API v0.3 §2.5 격자 방향(top=x·앞z아래행 / front=x·위윗행 / side=z·앞왼쪽)을 따르고, 남는 칸은 빈칸.
