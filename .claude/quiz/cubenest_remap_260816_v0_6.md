## 1. 현행 8유형 → 표준 리매핑

**테마(무엇을 다루나):** B measure · C 위모양 · D 삼면도 · A 안보이는나무 · G 최대최소.
**제시(given):** iso(겨냥도)·top(위모양)·sils(삼면도)·layers(층별)·numbered(수).
**질문(ask)→답:** num·markCount·mc·drawSil.

| 현행 id | 테마 | 제시(given) | 질문(ask) | 답 | 서버계산 | 상태 |
|---|---|---|---|---|---|---|
| `count` | B | iso | 총 개수 | num | `stats.count` | ✅ 유지 |
| `volume` | B | iso | 부피(cm³) | num | `count × edge³` | ✅ 유지 |
| `surface` | B | iso | 겉넓이(cm²) | num | `2×(위+앞+옆)×edge²` (마스터§4.2) | ✅ 유지·오목축 |
| `heightmap` | C | iso | 위 각 칸에 수 | markCount(N×N) | `heightMap` | ✅ 유지 |
| `facesMc` | D | iso | dir 실루엣 고르기 | mc | `silhouettes[dir]`+오답 | ✅ 유지 |
| `facesDraw` | D | iso | 위·앞·옆 그리기 | drawSil(N×N×3) | `silhouettes` | ✅ 유지·격자 N×N |
| `minmax` | **G** | sils(삼면도) | min/max/diff | num | `reverseCounts` | ✅ 유지(테마 재분류) |
| `hidden` | **A** | iso+top | (6종) | 6종 | **A-a~f로 교체** | ⚠ 폐기→교체 |

**변경점:**
- `minmax`는 사실상 **G(최대최소)** — 제시가 iso가 아니라 **삼면도(sils)** 여야 정합(현행은 iso로 주는데, G는 삼면도 given이 정석). 리매핑 때 제시를 `sils`로 교정.
- `hidden`은 폐기 → **A-a~f 6종**(설계서 v0.2)으로 교체.
- 나머지 6종은 테마·제시·질문 그대로, **답안 격자만 N×N 규칙(§4) 적용**.

## 2. 난이도 · 격자 · 고유축 = 독립 3축 (확정)

**핵심: 난이도 라벨과 격자 크기는 별개다.** 5×5×5여도 '하'가 가능(큰 판에 듬성). 경시용 7³·10³도 난이도가 아니라 격자 스케일.

```
① 난이도 라벨 (하/중/상/최상)   ← 사용자 선택. "얼마나 어렵나"
② 격자 스케일                   ← "판이 얼마나 크나". 난이도와 상호작용(격자만으론 난이도 미결정).
③ 유형별 고유 축                ← 유형마다 다른 난이도 동인
난이도 라벨 = f(밀도 · 모호성 · 유형 고유축)   ※ 격자 크기는 포함 안 함
```

### 2.1 난이도 라벨 = 실효 난이도 (밀도 U자 × 격자 상호작용)
난이도는 밀도에 **단조가 아니라 U자**(중간이 피크)이고, **격자와 상호작용**한다.
- **밀도 U자(count 기준):** 꽉참(규칙적→쉬움) · **중간 0.4~0.7(불규칙·가림→제일 어려움)** · 듬성(개수 적어 쉬움).
- **격자 상호작용:** 같은 중간밀도라도 3³은 쉽고 5³은 어렵다. → 난이도 ∝ 격자 × 밀도U자. **(격자는 난이도와 "직교"가 아니라 밀도와 상호작용; 격자만으론 난이도 미결정.)**
- **검증(hardness=채운수×밀도U):** 3³=5~15(쉬움) / 5³꽉참=23(쉬움) / **5³중간=69(최상)** / 4³중간=35(상). ✓
- 따라서 **"하=듬성", "격자=난이도"는 틀림.** 난이도 = f(격자 × 밀도U자 × 유형고유축 × 모호성). 사용자에겐 하/중/상/최상.

### 2.2 격자 스케일 (독립 축) — 지금은 기본만, 경시는 나중(Q2-C)
| 스케일 | gx·gz·maxH | 용도 | 상태 |
|---|---|---|---|
| **기본-S** | 3·3·3 | 교실·일반 | ✅ |
| **기본-M** | 4·4·4 | 일반 | ✅ |
| **기본-L** | 5·5·5 | 일반(큰 판) | ✅ |
| 경시-XL | 7·7·7 | 경시대회 | ⏳ 나중(별도 "경시 모드") |
| 경시-XXL | 10·10·10 | 경시대회 | ⏳ 나중 |
- **지금(P1):** 격자를 **독립 축**으로 데이터 구조화하되, 노출은 기본(S/M/L)만. **경시(7³·10³)는 값만 추가하면 되게** 스키마에 자리 확보.
- 난이도와 조합: (난이도 라벨) × (격자 스케일). 단 격자는 밀도와 상호작용해 실효난이도에 기여(완전 독립 아님). 예 "상·L", "하·L", "최상·S".
- **답안 격자 N×N:** N = max(gx,gz,maxH) (§4). 격자 스케일이 결정 → S=3, M=4, L=5, XL=7, XXL=10.

### 2.3 유형별 등급 프리셋 (Q2-B: 격자×밀도 조합 명시)
밀도 라벨: **꽉참**(≥0.85·규칙) · **중간**(0.4~0.7·불규칙, 가장 어려움) · **듬성**(≤0.35·개수적음). 격자: S3·M4·L5.
각 등급 = **허용 (격자·밀도) 조합의 집합**(생성 시 이 중 랜덤). 유형 고유축 함께.

**B count 개수 (더하기만 → 상한 낮음):** **지원 하~중.** (상·최상 없음: 격자가 커도 결국 덧셈이라 근본 난이도 상한.)
| 등급 | 허용 (격자·밀도) 조합 |
|---|---|
| 하 | S·any / **M·(듬성·꽉참)** / **L·(듬성·꽉참)** |
| 중 | S·중간 / M·중간 / L·중간 |

**B volume 부피 (개수 + 모서리길이 곱셈 → 상까지):** **지원 하~상.** (최상 없음: edge 곱이 붙어도 최상까진 과함.)
| 등급 | 허용 (격자·밀도, edge) |
|---|---|
| 하 | S·any, edge 1 |
| 중 | **S·(중간·꽉참) / M·any, edge 1~3** |
| 상 | **M·(중간·꽉참) / L·(중간·꽉참), edge 2+** |

**B surface 겉넓이 (오목판정 + (위+앞+옆)×2 → 최상까지):** **지원 하~최상.** + **오목축**.
| 등급 | 허용 (격자·밀도·오목) |
|---|---|
| 하 | S·any·볼록 |
| 중 | S·중간·볼록 / M·듬성 |
| 상 | M·중간·혼재 |
| 최상 | **L·중간·오목有** |
**C heightmap 위수:** count 조합 + 높이분산(평탄~큰굴곡).
**D facesMc 방향:** count 조합 + 오답유사도(뚜렷~미세반전).
**D facesDraw 삼면그리기:** S·중간(하)/M·중간(중)/M·중간·겹침(상). **최상 미지원**(L 그리기 부담).
**G minmax 최대최소:** 밀도는 **듬성 쪽**(자유도↑), 고유축=**max−min 폭**. 중=M·폭1 / 상=M·폭2 / 최상=L·폭3+. **하 미지원**(폭 안 나옴).
**A 안보이는나무:** 밀도는 **중간+높이 있어야 가림 생김**(듬성 금지). 중=유무·위치 / 상=+개수 / 최상=+모호성(A-f). **하 미지원.**
**(P1후) H 조작:** 리매핑 후 정의(조작수·색칠위치).

- **지원등급(랜딩 카드 levels 표시):** **count 하~중 · volume 하~상 · surface 하~최상** / facesDraw 하~상 / minmax·hidden 중~최상 / heightmap·facesMc 하~최상. (유형 계산복잡도가 최대등급 결정.)
- **gen-config:** `{ difficulty:{등급→[(grid,density)조합]}, gridScale:{S,M,L,(XL,XXL)}, perType:{ surface:{concave}, minmax:{spread,minGrade:중}, facesDraw:{maxGrade:상}, hidden:{sub,minGrade:중,densityMin} } }`.
- **표기 원칙:** 사용자엔 항상 하/중/상/최상. 속은 유형별 프리셋으로 구현.

## 3. 리매핑 구현 메모 (다음 데스크톱)

1. **gen 분기 표준화:** genProblem이 `{theme, given, ask}` 3필드로 분기하도록 리팩터(현행 `o.type` 단일 분기 → 테마·질문 조합). 단, 서버 계약(`_gp`)은 유지.
2. **minmax given 교정:** iso→sils(삼면도 제시). present에 `sils{top,front,side}` 추가.
3. **답안 격자 N×N:** drawSil·markCount·facesMc options 렌더를 `N=max(gx,gz,maxH)` 정사각 패딩(§4). 실루엣은 원치수 계산 후 좌상단 정렬.
4. **gen-config 독립축 구조:** `{ difficulty, gridScale, perType }`. 난이도 라벨과 격자 스케일 분리. 경시(XL/XXL)는 gridScale에 값만 추가하면 되게 자리 확보.
5. **hidden 제거:** 현행 hidden 분기 삭제, A-a~f 신설 자리 확보(다음 단계).

## 4. 답안 격자 N×N (재확인, 유형지도 §5.2)
격자 답안은 항상 정사각 **N×N, N=max(gx,gz,maxH)**. 4×4×3 → 위·앞·옆 모두 4×4. 교과서 관례·채점 단순화. N=3중/4상/5최상 난이도 연동.
